# MedBind 4.0 — Doctor Binder

Биндер для медиков GTA SAMP RP на AutoHotkey v2. Тёмный интерфейс в стиле Premium Dark: глубокий графит, холодный бирюзовый акцент, тонкие границы и компактные карточки.

## Что запускать

**`DoctorBinder.ahk`** — это всё приложение в одном файле (готовая сборка). Двойной клик — и всё работает.

Нужен установленный AutoHotkey v2: https://www.autohotkey.com
Не запускайте файл прямо из архива — распакуйте в обычную папку (например, «Документы/MedBind»).

## Как устроен репозиторий

```
binder1/
├── DoctorBinder.ahk      ← ЗАПУСКАТЬ ОДНО ЭТО (сборка: все модули в одном файле)
├── build.bat             ← пересобрать DoctorBinder.ahk из src/ (двойной клик)
├── build.ps1             ← сам скрипт сборки (build.bat только вызывает его)
├── src/                  ← исходники: модули, по одному файлу
│   ├── _header.ahk       ←   шапка сборки (то, что до первого модуля)
│   ├── App.ahk           ←   имя и версия приложения
│   ├── Json.ahk          ←   JSON-парсер
│   ├── Store.ahk         ←   данные: data\binder.json + резервная копия
│   ├── Sender.ahk        ←   отправка строк в чат игры
│   ├── Keys.ahk          ←   горячие клавиши
│   ├── Share.ahk         ←   обмен биндами (коды MEDBIND:…)
│   ├── Theme.ahk         ←   цвета, иконки, «дизайн-система»
│   ├── Controls.ahk      ←   кнопки, переключатели, поля, модальные окна
│   ├── Dialogs.ahk       ←   диалоги (ошибка, подтверждение…)
│   ├── Preview.ahk       ←   предпросмотр чата (понимает RP-команды)
│   ├── Toast.ahk         ←   уведомления в углу экрана
│   ├── MainUI.ahk        ←   главное окно
│   ├── Editor.ahk        ←   редактор бинда
│   ├── SettingsUI.ahk    ←   настройки и профиль
│   └── _footer.ahk       ←   хвост сборки (трей-меню и запуск)
└── data/                 ← создаётся приложением при первом запуске
```

Модули в `src/` лежат **в том же порядке, в котором они склеиваются** в сборку (от `App` до `SettingsUI`). Порядок зафиксирован в `build.ps1` (массив `$modules`).

## Как менять код и пересобрать

1. Правите модули в `src/`. **Не правьте `DoctorBinder.ahk` напрямую** — при следующей сборке ваши правки будут перезаписаны.
2. Двойной клик по `build.bat` (или в терминале: `build.bat` / `powershell -File build.ps1`).
3. Готово: `DoctorBinder.ahk` пересобран, запускается как раньше.

## Как проверить

| Шаг | Что делать | Что смотреть |
|---|---|---|
| 1. Сборка актуальна | двойной клик по `build.bat -Check` (или в cmd: `build.bat -Check`) | зелёное «OK: … совпадает побайтово». Если «РАСХОЖДЕНИЕ» — в окне будут показаны первые отличающиеся строки, нужно просто выполнить `build.bat` |
| 2. Нет синтаксических ошибок | `build.bat -Check -Compile` | компиляция через `ahk2exe` (ставится вместе с AutoHotkey) зелёным подтвердит, что ошибок нет |
| 3. Приложение живое | двойной клик по `DoctorBinder.ahk` | открывается главное окно + иконка в трее; рядом появилась папка `data/` с `binder.json`; в игре F11 открывает окно из любого места |

Если вы только переносили файлы или наводили порядок в структуре — достаточно шага 1: побайтовое совпадение сборки со `src/` гарантирует, что поведение приложения не изменилось.

## Главное окно

- Слева — категории со счётчиками и профилем; клик по строке статуса «Биндер активен» включает/выключает биндер.
- В центре — поиск (Ctrl+F или Ctrl+K), импорт, переключатель биндера и «Создать бинд»; ниже — карточки биндов с клавишей, категорией, предпросмотром строк и переключателем «Вкл»; внизу — пагинация.
- Справа — панель выбранного бинда: статус, описание, предпросмотр чата, статистика и действия. Если ничего не выбрано — подсказка и шпаргалка горячих клавиш.

## Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Главное окно | Ctrl+F / Ctrl+K | поиск |
| | Ctrl+N | новый бинд |
| | Ctrl+I | импорт |
| | Ctrl+D | дублировать |
| | Ctrl+A | выделить все |
| | Enter | редактировать |
| | Delete | удалить |
| | ↑ ↓ | выбор |
| | Ctrl/Shift + клик | несколько биндов |
| | Esc | очистить поиск или выделение |
| Редактор | Ctrl+S / Ctrl+Enter | сохранить |
| | Esc | закрыть |
| Игра (по умолчанию) | F11 | окно MedBind |
| | F12 | вкл/выкл биндер |
| | End | остановить отправку |
| | F9 | ввести ID |

## Синтаксис бинда

- Одна строка — одно сообщение.
- `#` в начале строки — комментарий, он не отправляется.
- `{wait 2000}` отдельной строкой — своя пауза.
- `{noenter}` — отправить строку без Enter.
- Переменные: `{nick}`, `{name}`, `{rank}`, `{org}`, `{id}`, `{time}`, `{date}`.

## Обмен

Кнопка «Поделиться» создаёт код `MEDBIND:…` и сразу копирует его в буфер обмена. Код также можно сохранить файлом `.medbind`. Другой игрок нажимает «Импорт» и вставляет код. Перед импортом видно, что будет добавлено.

## Данные

Хранятся в `data/binder.json` (рядом с `DoctorBinder.ahk`), резервная копия — `data/binder.backup.json`. Старые данные подхватываются автоматически. Папку `data/` можно нести в другое место как перенос настроек.
