# MedBind 4.0 — Doctor Binder

Биндер для медиков GTA SAMP RP. Приложение написано на **AutoHotkey v2** и предназначено для Windows.

## Быстрый запуск

1. Установите [AutoHotkey v2](https://www.autohotkey.com/). AutoHotkey v1 не подходит.
2. Скачайте или распакуйте репозиторий в обычную папку. Не запускайте программу прямо из ZIP-архива.
3. Запустите файл **`DoctorBinder.ahk` в корне репозитория** двойным щелчком. Это готовая автономная сборка — для обычного запуска Python не нужен.

При первом запуске рядом появится папка `data/` с настройками и биндами. Она намеренно не включается в Git.

## Как устроен проект

```text
DoctorBinder.ahk        Готовый файл для запуска; собирается из src/
src/
  core/                 Данные, JSON, отправка, горячие клавиши и обмен
  ui/                   Окна приложения, тема и элементы интерфейса
tools/build.py          Сборка модулей в DoctorBinder.ahk
tests/                  Автоматические проверки структуры и сборки
README.md               Эта инструкция
.gitignore              Исключения для пользовательских данных и временных файлов
```

Редактируйте файлы в `src/`, а не собранный `DoctorBinder.ahk`. Порядок объединения модулей задан в `tools/build.py`.

## Сборка после изменений

Для изменения исходников и пересборки нужен Python 3; сторонние Python-пакеты не требуются. В корне проекта выполните:

```bash
python tools/build.py
```

Команда обновит `DoctorBinder.ahk`. Перед запуском или отправкой изменений можно проверить, что сборка не устарела:

```bash
python tools/build.py --check
```

Если команда сообщает, что файл устарел, повторно запустите `python tools/build.py`.

## Как проверить проект

Автоматические проверки запускаются на Windows, macOS или Linux:

```bash
python -m unittest discover -s tests -v
python tools/build.py --check
```

Они проверяют, что исходники на месте, каждый модуль попадает в автономную сборку один раз и `DoctorBinder.ahk` соответствует исходникам. Это **не заменяет проверку самого окна AutoHotkey**: полноценный запуск возможен только на Windows с AutoHotkey v2.

### Ручная проверка приложения в Windows

1. Запустите `DoctorBinder.ahk` и убедитесь, что открылось главное окно.
2. Создайте тестовый бинд, сохраните его, закройте и снова откройте приложение — данные должны сохраниться.
3. Проверьте настройки профиля и импорт/экспорт на тестовых данных.
4. Проверяйте отправку сообщений только в безопасном месте игры и с тестовым текстом.

## Возможности и управление

- Главное окно: категории со счётчиками, поиск, список биндов, предпросмотр и панель действий.
- Ctrl+F / Ctrl+K — поиск; Ctrl+N — новый бинд; Ctrl+I — импорт; Ctrl+D — дублировать; Ctrl+A — выделить все.
- Enter — редактировать выбранный бинд; Delete — удалить; стрелки вверх/вниз — перемещение по списку; Ctrl/Shift + клик — выбрать несколько биндов; Esc — очистить поиск или выделение.
- В редакторе Ctrl+S / Ctrl+Enter — сохранить; Esc — закрыть.
- Горячие клавиши игры по умолчанию: F11 — открыть MedBind, F12 — включить/выключить биндер, End — остановить отправку, F9 — ввести ID.

### Синтаксис бинда

- Каждая строка — отдельное сообщение.
- `#` в начале строки — комментарий, он не отправляется.
- `{wait 2000}` отдельной строкой — пауза в миллисекундах.
- `{noenter}` — отправить строку без Enter.
- Переменные профиля: `{nick}`, `{name}`, `{rank}`, `{org}`, `{id}`, `{time}`, `{date}`.

### Обмен биндами

Кнопка «Поделиться» создаёт код `MEDBIND:…` и копирует его в буфер обмена. Код можно также сохранить в файл `.medbind`. Для импорта нажмите «Импорт» и вставьте код или выберите файл; перед добавлением будет показано содержимое.
