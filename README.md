# MedBind 4.0 — Doctor Binder

Биндер для медиков GTA SAMP RP на AutoHotkey v2. Тёмный интерфейс в стиле Premium Dark Medical Dashboard.

## Запуск
1. Установите AutoHotkey v2: https://www.autohotkey.com
2. Распакуйте архив в обычную папку, например «Документы/MedBind». Не запускайте файл прямо из архива.
3. Дважды щёлкните `DoctorBinder.ahk`. Это готовая сборка в одном файле.
4. Исходники по модулям лежат в папке `src`. Если запускаете `src/DoctorBinder.ahk`, рядом должна быть папка `lib`.

Данные хранятся в `data/binder.json`, а резервная копия — в `data/binder.backup.json`. Старые данные подхватываются автоматически.

## Горячие клавиши
| Где | Клавиши | Действие |
|---|---|---|
| Главное окно | Ctrl+F | поиск |
| | Ctrl+N | новый бинд |
| | Ctrl+I | импорт |
| | Ctrl+D | дублировать |
| | Ctrl+A | выделить все |
| | Enter | редактировать |
| | Delete | удалить |
| | ↑ ↓ | выбор |
| | Ctrl/Shift + клик | несколько биндов |
| | Esc | очистить поиск или выделение |
| Редактор | Ctrl+S / Ctrl+Enter | сохранить |
| | Esc | закрыть |
| Игра (по умолчанию) | F11 | окно MedBind |
| | F12 | вкл/выкл биндер |
| | End | остановить отправку |
| | F9 | ввод ID |

## Синтаксис бинда
- Одна строка — одно сообщение.
- `#` в начале строки — комментарий, он не отправляется.
- `{wait 2000}` отдельной строкой — своя пауза.
- `{noenter}` — отправить строку без Enter.
- Переменные: `{nick}`, `{name}`, `{rank}`, `{org}`, `{id}`, `{time}`, `{date}`.

## Обмен
Кнопка «Поделиться» создаёт код `MEDBIND:…` и сразу копирует его в буфер обмена. Код также можно сохранить файлом `.medbind`. Другой игрок нажимает «Импорт» и вставляет код. Перед импортом видно, что будет добавлено.
